# Karriereportal Kesseler — Kundenvorschau

Entwurfsstand des Karriereportals für Kesseler Garten- und Landschaftsbau,
erstellt von NEXAS Media. Eine einzige HTML-Datei, alles eingebettet.

**Das hier ist nur die Vorschau.** Quellcode, Serverskripte und Dokumentation
liegen in einem privaten Repository.

Nicht für Suchmaschinen bestimmt (`robots.txt`, `noindex`). Das Bewerbungsformular
verschickt in dieser Fassung nichts — dafür braucht es PHP auf dem Zielserver.
